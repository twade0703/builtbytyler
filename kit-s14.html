S14Ball tilt switch

Tilt

Tells you when it's tipped over.

Wire it to

  3. OUTD4 · GPIO 4Signal: HIGH or LOW

Power: plug the 9 V battery into the power module, or plug the ESP32 into USB.

Try it

Tip the board over

Upright = closed (OUT HIGH); tipped past ~45 deg = open (OUT LOW).

Code

Download Arduino sketch
/*
  BuiltByTyler Sensor Kit - S14 TILT (Ball tilt switch)
  Board: ESP32-WROOM-32 DevKit V1 (30-pin), Arduino-ESP32 core 3.x, "ESP32 Dev Module"

  Prints upright / tilted. Upright = switch closed = OUT HIGH;
  tipped past ~45 degrees = OUT LOW.

  Wiring (module pin -> ESP32 pin):
    GND  -> GND
    VCC  -> 3V3
    OUT  -> GPIO 4

  Library: none needed
  Serial Monitor: 115200 baud
*/

#define OUT_PIN  4

void setup() {
  Serial.begin(115200);
  pinMode(OUT_PIN, INPUT);   // the board has its own pull resistor, so plain INPUT
}

int last = -1;   // last state we printed (-1 = nothing yet)

void loop() {
  int s = digitalRead(OUT_PIN);
  if (s != last) {             // only print when something changes
    Serial.println(s == HIGH ? "1  upright" : "0  tilted");
    last = s;
  }
  delay(10);
}
